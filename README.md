## 📌 About

The second phase of Travigo expands the platform with new pages (destinations, login, sign-up), complete **Figma UI/UX wireframes** and a fully **mobile-first** layout, still in pure HTML5 and CSS3.

> 🎓 Built during my training at **YouCode (UM6P) · Full Stack Web Development**.

## ✨ Features

- 🗺️ Destinations page
- 🔐 Login & sign-up pages
- 🎨 Figma wireframes & mockups
- 📱 Mobile-first responsive design
- 🗂️ Planned with Trello

## 🛠️ Tech Stack

`HTML5` · `CSS3` · `Figma` · `Trello`

## 🚀 Getting Started

```bash
git clone https://github.com/razaane/Travigo-Travel-V2.git
cd Travigo-Travel-V2
# open index.html in your browser, or serve it locally:
npx serve .
```
